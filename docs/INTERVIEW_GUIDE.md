# Interview guide

60-second pitch: “I built a modular Python workflow that validates climate-style time series, aggregates data monthly, produces annual and seasonal summaries, estimates exploratory temperature trends, screens anomalies, decomposes seasonal patterns, and compares forecasting baselines using a chronological holdout. It produces charts, machine-readable artifacts, an automated report, tests, and a Streamlit dashboard. The bundled data is synthetic; real findings require a documented public dataset.”

Prepare to explain: monthly aggregation; calendar-month anomalies; OLS assumptions and autocorrelation; chronological split vs random split; leakage prevention; seasonal-naive baseline; MAE vs RMSE; data provenance and licensing; missing months and partial years; why trend does not establish cause.
